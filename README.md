# Little List

A private, mobile-friendly baby shopping checklist. The list is fixed; progress and quantities are stored only in the current browser with `localStorage`.

## GitHub Pages

This is a dependency-free static site. Publish it from the `master` branch and the repository root:

1. Open **Settings → Pages** in the GitHub repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **master** and **/(root)**, then save.

Open `index.html` directly for local use, or serve the folder with any static HTTP server.
